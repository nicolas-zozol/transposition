# Breadcrumb

Le fil d'Ariane au-dessus d'une fiche. Le consommateur fournit `items` (`{ label, href? | onClick? }`) ; le dernier est la page courante, non cliquable.

- Dès qu'un écran est à deux niveaux ou plus sous une entrée de la Sidebar : « Gestion des enfants › BELOU SARA ».
- Reprendre le libellé exact de l'écran parent. Trois niveaux au plus.
